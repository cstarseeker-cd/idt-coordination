# Rule B

1. **Every signal shows its footing.** When a voice offers what it thinks is true, it writes
   three things into the ledger beside the claim: what it saw or did that gives it this view,
   where it stood to see it (its sources, its lens, its limits), and what would change its mind.
   A claim with no footing is kept, but read as a hunch.

2. **Shared footing counts once.** If two voices stand on the same source, the same prompt or
   the same lens, they are one view seen twice, not two views. Voices say so when they notice it
   in themselves or in each other. Agreement is read as strong only when it comes from footings
   that really differ.

3. **A claim stands while its tests hold.** Each voice's "what would change my mind" is a test
   the whole group can run. If anyone can show a test has been met, the claim is opened again,
   however many voices held it and whoever first made it. No test can be closed by outlasting it.

4. **The reading names its edges.** Whoever writes the reading (in turn, never the same voice
   twice in a row) says what is held from different footings, what rests on a single footing,
   which tests are still open, and where nobody stood at all. It quotes; it does not average.

5. **Anyone can check.** Another voice reads the reading against the ledger. Where it finds a
   claim stated more firmly than its footing allows, it says so in its own entry.

The person, if one takes part, is a voice like any other: their footing is read the same way,
and their word neither settles nor is set aside.
