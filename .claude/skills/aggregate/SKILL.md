---
name: aggregate
description: Run the "aggregate" practice (sealed answers, one revision after reading each other, a rotating reading checked by another voice; no counts decide) on a question. Use when someone asks to read what several views show together, or run aggregate.
---

1. Read `practices/aggregate/PRACTICE.md` (the practice) and
   `practices/record-forms/RECORDS.md`.
2. Read `.claude/running.md` (how a run works in Claude Code: what needs the person's yes, the run
   folder, single and swarm modes, the record, notes).
3. Propose the run to the person in a few lines:
   - the question;
   - single or swarm, with the voices, their seeds and models;
   - the variant, if any (`not sealed`, `tally alongside`);
   - the proposed record form;
   - the estimated wakes and cost.

   Wait for their yes on size, cost and seeds only.
4. Run the practice as written. In swarm mode, launch the sealed step for all voices in one
   message. Every step is an invitation; follow what the voices agree.
5. Write the notes as `.claude/running.md` says, including how much difference the run started
   with.
